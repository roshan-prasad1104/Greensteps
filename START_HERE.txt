🎮 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. USER SIGNS UP
   ├─ Enter name, email, department, campus
   ├─ Set initial transport preferences
   └─ Account created in Firebase Firestore

2. USER LOGS IN
   ├─ Enter email and password
   ├─ Receive JWT authentication token
   └─ Redirected to dashboard

3. USER LOGS TRANSPORT
   ├─ Select transport mode
   ├─ Enter distance traveled
   ├─ System calculates:
   │  ├─ Emissions (distance × factor)
   │  ├─ Points (distance × 0.1 × multiplier)
   │  └─ Streak progress
   └─ Dashboard updates in real-time

4. POINTS EARNED
   ├─ Base: distance × 0.1
   ├─ Eco-friendly modes: +50% bonus
   ├─ Streak bonuses at 5,7,15,30 days
   └─ Leaderboard positions updated

5. USER VIEWS STATS
   ├─ Total emissions and points
   ├─ Daily/weekly/monthly breakdown
   ├─ Charts and analytics
   ├─ Leaderboard position
   └─ Personalized suggestions
